# Birim Coffee

Айбарчын Икрамованын кофе дүкөнү тууралуу окуу долбоору.

## Мүмкүнчүлүктөр
- Телефонго ылайыкташкан кыргызча сайт жана күндүзгү/түнкү тема.
- Меню категориялары, себет, санды өзгөртүү жана серверде эсептелген баа.
- Сынамык заказдар Cloudflare R2 сактагычында өзүнчө объект болуп сакталат.
- Админ: товар кошуу/өзгөртүү/жашыруу, HTTPS сүрөт шилтемеси, заказдын абалы жана өчүрүү.
- Кайталанган сурамдан бир эле заказ түзүлөт. Товарды параллель өзгөртүү текшерилет.

## Иштетүү жана коргоо
Node.js 22+ керек. Тышкы npm пакеттери талап кылынбайт.

```sh
npm test
npm run build
```

`dist/server/index.js` — Cloudflare Worker ES module. Ал `BUCKET` деген R2 binding талап кылат. Sites бул binding'ди `.openai/hosting.json` аркылуу туташтырат. `public/` папкасын GitHub Pages'ке гана чыгарсаң сервер жана админ API иштебейт.

Бул версия Sites'те **owner-private** болушу керек: платформа сайт ээсин ChatGPT аркылуу киргизет, API админ операцияларында `oai-authenticated-user-id` текшерет. Мүчөлөрдү кошуудан же сайтты жалпыга ачуудан мурун серверде сайт ээсинин ID'си боюнча өзүнчө роль текшерүү кошулууга тийиш. Сырсөз коддо жок.

Бул окуу долбоору; чыныгы төлөм жүргүзүлбөйт. Байланыш маалыматы бар сынамык заказдарды админден өчүрүүгө болот. Сүрөттөр Unsplash'тан, шрифттер Google Fonts'тан жүктөлөт. Алар жеткиликсиз болсо системалык шрифт жана альтернативдик сүрөт тексти колдонулат.

## Файлдар
- `public/index.html`, `style.css`, `app.js` — интерфейс.
- `public/admin.html` — админ интерфейси.
- `worker/api.js` — сервер, валидация жана сактоо.
- `scripts/build.mjs` — көз карандылыксыз Worker жыйноо.
- `tests/api.test.mjs` — уруксат, заказ, каталог жана сактоо текшерүүлөрү.
